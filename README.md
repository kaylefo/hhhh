# Kulur

Kulur is a mobile-first color-mixing game. Roll procedural colors, place them on an expanding hex board, and discover exact sRGB colors through OKLab edge and vertex mixing.

## Start

```bash
npm install
npm run dev
```

## Verification

```bash
npm run lint
npm run typecheck
npm run test
npm run build
npm run test:e2e
npm run check
```

## Stack

React, TypeScript, Vite, PixiJS, IndexedDB (idb), Zustand, Zod, Vitest, Playwright, vite-plugin-pwa
